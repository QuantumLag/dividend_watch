## ✨ Features

* **🔐 Authentication** — Secure email/password and OAuth (Google, GitHub) handled seamlessly via Supabase Auth.
* **📊 Portfolio Dashboard** — Track your current holdings, monitor incoming dividend income, and view deep portfolio analytics.
* **📅 Dividend Calendar** — A highly visual calendar tracking upcoming ex-dividend dates and payout dates.
* **👀 Watchlist** — Keep an eye on potential tickers without adding them to your active holdings.
* **🔔 Alerts** — Set custom notification rules for upcoming ex-dates, dividend cuts, yield increases, and payment days.
* **📈 Income Forecasting** — Project your future passive income utilizing advanced yield calculations and compounding models.
* **💰 Tiered Pricing** — Flexible plans including Free (up to 10 stocks), Pro (unlimited tracking + advanced tools), and Enterprise solutions.
* **🎨 Premium UI** — A stunning user interface featuring a parallax hero section, smooth Framer Motion animations, dark/light mode toggles, and full mobile responsiveness.

| **Styling** | Tailwind CSS 4, Radix UI, shadcn/ui |
