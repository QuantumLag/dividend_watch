DividendWatch
The modern platform for dividend investors. Track ex-dates, calculate yields, and forecast your passive income with precision.

Features
🔐 Authentication — Email/password and OAuth (Google, GitHub) via Supabase Auth
📊 Portfolio Dashboard — Track holdings, monitor dividend income, and view portfolio analytics
📅 Dividend Calendar — Visual calendar of upcoming ex-dates and payment dates
👀 Watchlist — Follow tickers without holding them
🔔 Alerts — Custom notification rules for ex-dates, cuts, increases, and payments
📈 Income Forecasting — Project future passive income with yield calculations
💰 Tiered Pricing — Free (10 stocks), Pro (unlimited + advanced tools), and Enterprise plans
🎨 Premium UI — Parallax hero, smooth animations, dark/light mode, and responsive design
Tech Stack
Framework: Next.js 16 (App Router, React 19)
Backend: Supabase (Auth, PostgreSQL, Row-Level Security)
Styling: Tailwind CSS 4 + Radix UI + shadcn/ui
Animations: Framer Motion
3D: React Three Fiber + Drei
Charts: Recharts
Language: TypeScript
